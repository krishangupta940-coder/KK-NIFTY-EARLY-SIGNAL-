## About
KK NIFTY EARLY SIGNAL is a market
early signal application for NIFTY 50.

## Features
- NIFTY 50 Market Signals
- Buy and Sell Alerts
- Market Trend Analysis
- Support and Resistance
- Zerodha Kite Connect API
- Android Mobile Support

## Technology
- Python
- Zerodha Kite Connect
- FastAPI
